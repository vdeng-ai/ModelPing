# 模型选择与测试交互

## 页面结构

保留无侧栏的顶部导航和「凭据解码 / API 测试」双列工作区，移动端上下排列。
API 测试按下面的顺序组织：

```text
连接
  供应商 · Base URL · API Key
  获取模型 · 查询余额

选择模型                           全球模型目录
  搜索：已配置模型 + 全球目录
  添加自定义模型 · 加入状态 · cc-switch

请求设置：超时 / token 上限 / 并发
                         高级参数 · 测试选中模型

测试结果                             结果筛选
  协议 · 状态 · 延迟 · 用量 · 响应详情
```

API Key 下重复的「密钥处理与导入」已移除。解码操作统一在左侧完成，
保留 Base URL、API Key 的复制和解码结果带入连接表单。
原“更多”中的添加模型、结果筛选、加入状态和 cc-switch 都直接展示，窄屏换行而不隐藏。
结果行的保存、加入状态和移除也直接展示。

## 模型搜索

选择模型支持按模型名称、实际请求 ID、目录供应商名称搜索，不要求先把目录模型导入预设。
同一请求 ID 合并展示来源；精确 ID 优先；一次最多渲染 60 项并提示继续缩小关键词范围。

选中已有模型时复用当前连接对应的模型行；选中新目录模型时创建会话内的自定义模型行并立即选中。
发送请求使用目录的实际 ID，而不是展示名称；同名但请求 ID 不同的模型不会被错误复用。
共享模型的归属检查覆盖全部供应商映射，而不是只检查第一个供应商。

选择模型不改变当前供应商、Base URL 或 API Key，不触发测试，不自动保存供应商预设。
请求协议沿用当前连接的匹配规则。目录收录不代表当前接口支持该模型，仍需明确点击测试验证。

## 目录与参数

「全球模型目录」位于模型区右上角，在独立弹窗里提供手动更新、按来源浏览和导入预设。
搜索框与目录管理共享一份缓存状态：首次打开按需读取服务端缓存，输入关键词只进行本地过滤。
只有点击更新按钮才同步上游目录。加载失败保留本地模型选择并提供重试；空目录提示手动更新。

「高级参数」位于测试按钮旁，在一个弹窗中直接展示测试输入、并发、超时、token 上限、
重试次数和 User-Agent，不再出现嵌套折叠。修改沿用原有参数保存规则，影响后续请求，
关闭弹窗不自动发起测试。测试过程中禁用模型和参数切换入口。

## 键盘、触屏与回归

方向键定位候选，Enter 选中，输入法组词时 Enter 不选中；Escape 关闭候选并保留原模型，
Tab 离开搜索框。`/` 聚焦模型搜索，弹窗关闭后恢复入口焦点，页面切换不抢占正在输入的焦点。
候选列表支持触屏点击，所有低频操作仍然可见。

验证命令：

```sh
npm run verify
npm run test:workbench:browser
npm run test:toolbox:browser
```

浏览器测试使用本地模拟 API，不调用真实供应商或消耗付费模型额度。
覆盖 320、390、768、1440 像素以及明暗主题；截图位于
`node_modules/.cache/workbench-browser/`。这不等同于真实供应商集成验证或完整屏幕阅读器审计。
